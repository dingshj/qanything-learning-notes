# 01_项目介绍与环境准备

## 1. 这个项目是干什么的？

**QAnything** 是一个**本地知识库问答系统**，由网易有道开源。它的核心功能是：

### 打个比方
想象你有一个超级智能的图书馆管理员。你可以把各种文档（PDF、Word、txt、图片等）扔给它，然后随时问它问题，它会从这些文档中找到答案回答你。

### 核心功能
1. **文件上传**：支持上传 PDF、Word、图片、网页等格式的文件
2. **智能问答**：上传文件后，可以向系统提问，系统会从已上传的文档中找出答案
3. **知识库管理**：可以创建多个知识库，每个知识库存放不同主题的文档

## 3. 入口文件：`sanic_api.py`

这是整个程序的起点，类似于一本书的"目录"。它的主要作用是：

1. **初始化服务器**：设置好监听的端口（默认 8777）
2. **加载 AI 模型**：根据配置加载大语言模型
3. **注册路由**：告诉服务器"当用户访问某个网址时，调用哪个函数来处理"

### 第169-174行：创建服务器


**生活类比**：就像租下一个店面（服务器），然后把招牌挂上去（设置路由）。


### 第225-243行：注册路由


**生活类比**：就像餐厅的前台，"有人点菜就找服务员A，有人买单就找服务员B"。

## 5. 常用语法解释

### 装饰器 `@app.before_server_start`
装饰器是 Python 的一种特殊语法，可以在不修改函数本身的情况下，给函数添加新功能。

```python
@装饰器名
def 函数名():
    # 函数内容
```

**类比**：就像给手机贴膜、装手机壳，不改变手机功能，但增加了保护。

### 异步函数 `async/await`
```python
async def 函数名():
    await 某个耗时操作()
```

**解释**：`async` 允许程序在等待某些操作（如网络请求）时，同时做其他事情，提高效率。

**类比**：就像你做饭时可以边煮汤边切菜，而不是等汤煮完才开始切菜。
